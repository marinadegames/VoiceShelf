# VoiceShelf

> Голосовые заметки без облака, подписок и расхода токенов.

VoiceShelf записывает или принимает аудио и видео, локально расшифровывает
русскую речь с английскими терминами, структурирует текст и строит схему.

## Что умеет

- запись с микрофона и живая звуковая волна;
- локальная расшифровка через Whisper;
- разбор заметки на тезисы, задачи, решения и вопросы;
- схемы, словарь терминов и библиотека записей;
- светлая и тёмная темы.

## Запуск

Нужны **Python 3.9+**, **Flutter 3.47.7+** и полный **Xcode** для macOS.

```bash
# macOS / Linux
./start.sh
```

```powershell
# Windows
.\start.ps1
```

При первом запуске разрешите доступ к микрофону. Затем откройте
**«Модели и диагностика»** и установите предложенные модели Whisper и Qwen.

## Как пользоваться

1. Запишите голос или выберите аудио/видео.
2. Нажмите **«Расшифровать»**.
3. Выберите **«По полочкам»** или **«Схема»**.

Результат можно скопировать или сохранить в Markdown.

## Всё локально

Аудио, тексты, словарь и модели остаются на компьютере. VoiceShelf не использует
облачные API; Ollama доступна только через `127.0.0.1`. Интернет нужен лишь для
первичной установки зависимостей и выбранных моделей.

## Стек

`Flutter` · `Dart` · `Python` · `faster-whisper` · `Ollama` · `Qwen` · `AVFoundation`

```bash
.venv/bin/python -m pip install -r requirements-build.txt
./packaging/build-macos-dmg.sh
```
